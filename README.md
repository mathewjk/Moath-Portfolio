# Moath Hussein — Executive Portfolio

A simple, elegant single-page executive portfolio for Moath Hussein, Enterprise Strategy & Transformation Executive.

- `index.html` — the entire site (self-contained HTML/CSS/JS; Google Fonts loaded from CDN)
- `server.js` — optional tiny static server for local preview: `node server.js` then open http://localhost:4322

Deployable as-is to GitHub Pages, Netlify, or any static host.
